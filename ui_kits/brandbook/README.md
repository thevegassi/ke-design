# Brandbook document kit

Click-through recreation of the guideline document on the **`brandbook`** page of the source file — the label's own primary design surface. Eight representative pages of the 26.

**Files**
- `index.html` — page navigator (tabs + prev/next).
- `Pages.jsx` — the shared `Page` shell (1920×1080, 108px margin, folio at x=1811.641 / y=83) plus each page.

| Page | Source frame |
| --- | --- |
| Обложка | `brandbook/01` |
| Описание компании | `brandbook/03` |
| Раздел (chapter divider) | `brandbook/05` |
| Охранное поле | `brandbook/07` |
| Основные цвета | `brandbook/08` |
| Цветовые сочетания | `brandbook/09` |
| Шрифты | `brandbook/10` |
| Паттерны | `brandbook/13`–`17` |

Built entirely from `SectionHeading`, `ColorSwatch`, `LogoTile`, `ServiceCard`, `PatternField`, `Logo` and `Icon`.

**Abbreviated on purpose:** the typeface page shows four Nunito Sans weights rather than the source's full specimen ladder, and the pattern page shows all four patterns in one grid rather than one page each. Layout, colour and type values are literal.
