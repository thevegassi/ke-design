The brand's only badge — a fully-rounded pill. Lime for content tags on posts, stories and thumbnails; outlined for the URL in a deck header.

```jsx
<Tag>snippet</Tag>
<Tag>backstage</Tag>
<Tag variant="outline">www.keyent.kz</Tag>
```

Tag copy is always lowercase, one word where possible. On lime the ink is `--ke-lime-ink` (#506600), never black and never white.
